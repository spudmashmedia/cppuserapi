# Prerequisite

## For Linux / MacOS
### Required Tooling
- [Brew ](https://brew.sh/)
- Clang or [gcc](https://formulae.brew.sh/formula/gcc#default) 
- [Vcpkg](https://vcpkg.io/en/)
  
### Coding Environment
Use what ever IDE you like but this is my setup:

- [tmux](https://formulae.brew.sh/formula/tmux#default) Terminal multiplexer - lets you split up your terminal into panes
- [FiSH](https://fishshell.com/) nice shell
- [Helix]([http](https://helix-editor.com/)) if you want to break away from VSCode. Less noise, less mouse usage - learn the keybindings 👍
- [Httpie](https://formulae.brew.sh/formula/httpie#default) TUI to perform HTTP/HTTPS requests
- [Postman](https://www.postman.com/downloads/) if you don't want to use Httpie... just use Httpie 👍
- [mitmproxy](https://formulae.brew.sh/cask/mitmproxy#default) for testing traffic from the API
