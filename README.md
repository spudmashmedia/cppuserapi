# cppuserapi
An API utilising Crow Lib

A C++ API using [Crow](https://crowcpp.org/master/) that integrates with [randomuser.me](https://randomuser.me/documentation) API.

This repo demonstrates:
  - Crow REST API
  - generating a Strongly Typed proxy library for randomuser.me
